# Qyrox

> A programming language built from Python, shaped into something new.

Qyrox is a lightweight programming language created from scratch, designed with readable and simple syntax.

## 🚀 Current Version

**Qyrox v0.0.9 — Development Release**

Qyrox is currently under active development. The language is being improved through testing, bug fixing, and new features.

## ✨ Features

- Readable programming syntax
- Variables
- Functions
- Conditions
- Loops
- Classes and objects
- Exception handling
- File operations
- Built-in functions
- Interactive REPL
- Qyrox project management through the `qyx` CLI
