Qyrox

A programming language built from Python, shaped into something new.

Qyrox is a lightweight programming language designed with readable, simple, and flexible syntax. Built to make programming more approachable, Qyrox combines familiar programming concepts with its own language structure and features.

🤖 Built-in AI

Qyrox v0.0.10 introduces built-in AI functionality.

AI commands can be activated directly through Qyrox syntax:

gpt['command']

This provides a way to interact with AI functionality directly from Qyrox code.

💻 Example

Let name = "Qyrox"

show["Hello from " + name]
